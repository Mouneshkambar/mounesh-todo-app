# JavaScript Logic & State Management - To-Do List

A client-side To-Do List application built with HTML, CSS, and vanilla JavaScript.

## Features

- Create tasks
- Read/display tasks
- Update tasks
- Delete tasks
- Mark tasks as completed
- Filter by All, Active, and Completed
- Persist tasks with `window.localStorage`
- Dynamic DOM creation and event listeners
- Responsive UI

## How to run

Open `index.html` in a browser.

No backend or package installation is required.
